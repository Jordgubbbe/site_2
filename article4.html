Программирование

Фреймворк
Готовая структура и набор инструментов для разработки приложений. Пример — Ruby on Rails.
Ruby
Язык программирования, на котором написан Ruby on Rails.
Ruby on Rails
Веб-фреймворк, созданный Ханссоном в 2004 году.
MVC (Model-View-Controller)
Архитектурный шаблон, разделяющий приложение на три части: модель (данные), представление (интерфейс) и контроллер (логика).
DRY (Don't Repeat Yourself)
Принцип программирования: не повторяй один и тот же код дважды.
Open source
Программное обеспечение с открытым исходным кодом, которое можно свободно использовать и изменять.

Гонки и автоспорт

24 часа Ле-Мана
Легендарная гонка на выносливость, которая проходит во Франции с 1923 года. Победа в ней — одно из высших достижений в автоспорте.
WEC (World Endurance Championship)
Чемпионат мира по гонкам на выносливость, организованный FIA. Включает 24 часа Ле-Мана как один из этапов.
LMP2
Класс прототипов в гонках на выносливость. Машины этого класса чуть медленнее LMP1, но тоже очень быстрые.
LMGTE Am
Класс GT-машин для любительских экипажей в гонках на выносливость.
ALMS (American Le Mans Series)
Американская серия гонок на выносливость, существовавшая с 1999 по 2013 год.
OAK Racing
Французская гоночная команда, за которую Ханссон выступал в 2011–2013 годах.
Aston Martin Racing
Гоночное подразделение британской марки Aston Martin. За эту команду Ханссон победил в Ле-Мане в 2014 году.

Веб и интернет

HTML
HyperText Markup Language — язык гипертекстовой разметки, с помощью которого создаётся структура веб-страниц.
CSS
Cascading Style Sheets — каскадные таблицы стилей. Отвечают за внешний вид веб-страниц: цвета, шрифты, отступы, расположение элементов.
HTTP
HyperText Transfer Protocol — протокол передачи гипертекста. Основной протокол, по которому браузер получает веб-страницы с сервера.
HTTPS
Защищённая версия HTTP. Данные между браузером и сервером шифруются — это безопаснее.
Сервер
Компьютер, который хранит сайт и отдаёт его браузеру по запросу.
Браузер
Программа для просмотра веб-страниц: Chrome, Firefox, Safari, Edge и другие.
